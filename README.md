## ✨ Flagship Features

### 🧠 AI Student Risk Radar
Move beyond static data. Our predictive analytics widget actively monitors student performance and attendance, automatically flagging students at high risk of falling behind with actionable AI insights and 1-click intervention alerts.

### ⚡ Global Omni-Command Center
Navigate at the speed of thought. Press `Cmd + K` anywhere in the application to summon a beautiful, glassmorphic command palette. Jump to modules, execute quick actions, or search for students instantly.

### 📱 Smart Attendance Roster
Throw away the paper ledgers. The Smart Tap interface allows faculty to mark attendance in seconds with a highly visual grid. Defaults to 100% present—just tap the absent students. Fully optimized for mobile and tablet touchscreens.

### 🎨 Premium Aesthetics
Built strictly following "The Stitch Rule" design system. Features a gorgeous `Canvas` and `Primary Ink` color palette, perfectly rounded components, and fluid micro-animations that make managing an institution a joy, not a chore.

## 🚀 Getting Started

Follow these steps to run Campus ERP locally on your machine.

### 1. Clone the repository
```bash
git clone https://github.com/Kiran-Kumbar/Campus-ERP.git
cd Campus-ERP
```

### 2. Install dependencies
```bash
npm install
```

### 3. Initialize the Database
The project uses a local SQLite database for blazing-fast local development.
```bash
npm run db:push
npm run db:seed
```

### 4. Start the development server
```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser to view the application.
